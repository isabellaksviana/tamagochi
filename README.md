# Tamagochi

Um bichinho virtual: você adota, alimenta, brinca e solta. Os bichos ficam salvos no navegador e sobrevivem ao F5.

Feito para praticar Vue 3 com TypeScript: props e eventos tipados, estado derivado com `computed`, `watch` com `localStorage` e modal com slot.

**No ar:** https://tamagochi.isabellaviana.com

## Rodar

```bash
pnpm install
pnpm dev
```
